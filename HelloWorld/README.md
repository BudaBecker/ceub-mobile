## Diferença entre Android Studio, Android SDK e sistema Android

O **Android Studio** é a IDE oficial usada para escrever, editar e depurar o código dos aplicativos Android. O **Android SDK** (Software Development Kit) é o conjunto de ferramentas, bibliotecas e APIs necessárias para compilar e testar esses aplicativos, incluindo emuladores e versões da plataforma. Já o **sistema Android** é o sistema operacional que roda nos dispositivos reais (celulares, tablets) e executa os aplicativos já compilados. Em resumo: o Android Studio é onde se desenvolve, o SDK é o que permite construir e testar, e o Android é o sistema que efetivamente executa o app no usuário final. Os três trabalham juntos, mas cada um tem uma função distinta no ciclo de desenvolvimento.
